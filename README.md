# Nova Browser

一个运行在网页里的浏览器。界面本身是网页，配一个渲染代理服务，让第三方网站能在窗口中被正常加载和浏览。

## 在线使用

| 版本 | 地址 | 能力 |
| --- | --- | --- |
| **完整版（公网，推荐）** | <https://nova-browser.app.workbuddy.host/> | 打开即用，无需安装：第三方网站加载、代理、下载管理全部可用 |
| 静态版（GitHub Pages） | <https://jiehag.github.io/llq/> | 仅界面与官方播放器；网页代理需要服务端，多数网站无法加载 |
| 本地完整版 | <http://127.0.0.1:7180> | 用自己电脑的网络出口，可访问公网实例够不到的站点 |

> 公网完整版运行在云沙箱，**出口为中国大陆网络**：国内站点（百度 / 知乎 / B 站 / 微博 / 抖音 / 淘宝 / 腾讯 / 掘金等）正常；Google、YouTube、X、维基百科、GitHub 等墙外站点不可达；少数小站会拒绝机房 IP。这类站点请用本地版（走你自己的家宽出口）。

## 部署

服务已满足云托管要求：零第三方依赖、监听 `PORT`、绑定 `0.0.0.0`，并内置公网安全护栏。

**公网模式**（云平台自动注入 `PORT`，或手动 `NOVA_PUBLIC=1`）会启用：

- **SSRF 防护**：拒绝代理到回环 / 内网 / 链路本地 / 云元数据地址（含 DNS 解析层过滤，防域名指向内网绕过）
- **按 IP 限流**：默认 1500 请求/分钟，可用 `NOVA_RATE_MAX` 调整

```bash
# 本地（局域网模式，不启用护栏）
node server.js

# 公网模式
PORT=3000 NOVA_PUBLIC=1 node server.js
```

仓库内已备好各平台部署清单，任选其一：

| 方式 | 文件 | 说明 |
| --- | --- | --- |
| Docker | `Dockerfile` | `docker build -t nova . && docker run -p 7180:7180 nova` |
| Render | `render.yaml` | 新建 Blueprint 指向本仓库，自动读取配置 |
| Fly.io | `fly.toml` | `fly launch --no-deploy && fly deploy` |
| 通用 PaaS | `Procfile` | Railway / Heroku 等直接识别 |

## 快速开始

双击 `start.bat`，或在命令行执行：

```bash
node server.js
```

然后浏览器打开 <http://127.0.0.1:7180>

服务监听 `0.0.0.0`，**同一 WiFi 下的手机**可访问 `http://<电脑IP>:7180` 使用完整版（启动时控制台会打印局域网地址）。手机打不开时，检查 Windows 防火墙是否放行。

> 必须通过 `http://127.0.0.1:7180` 或局域网地址打开。直接以 `file://` 方式打开 `index.html` 时，渲染代理不可用，大部分网站会因禁止 iframe 嵌套而加载失败。

## 为什么需要 server.js

浏览器安全策略里，网站可以通过 `X-Frame-Options: DENY` 或 CSP 的 `frame-ancestors` 声明「禁止被别的页面嵌入」。绝大多数网站都开了这个开关，所以纯粹的前端外壳无法加载它们。

`server.js` 做的是渲染代理：

| 能力 | 说明 |
| --- | --- |
| 解除嵌套限制 | 剥离 `X-Frame-Options`、CSP 等响应头 |
| 页面重写 | 注入 `<base>` 与导航劫持脚本，页面内点击、表单提交、`window.open` 都交回浏览器外壳处理 |
| 会话保持 | 服务端 Cookie Jar，按站点隔离，登录态可用 |
| 存储隔离 | 按站点给 `localStorage` / `sessionStorage` 加命名空间，避免所有网站共用同一份存储 |
| 资源透传 | 非 HTML 资源原样流式转发，保留 `Range` 分段 —— 视频可以拖动进度 |
| 编码兼容 | 自动识别 GBK / GB2312 等编码并统一转 UTF-8 |
| 图标代理 | `/__fav` 拉取站点 favicon，失败时回退为首字母色块 |

## 功能

**浏览**
- 多标签页：新建 / 关闭 / 恢复（Ctrl+Shift+T）/ 中键关闭 / 内存级前进后退
- 智能地址栏：自动区分网址与搜索词，带联想建议（可切换搜索引擎）
- 书签栏 + 书签管理、历史记录分组、下载记录
- 页面缩放、加载进度条、HTTPS 状态指示、明暗主题
- 站点级的渲染代理开关（遇到问题可单站切换重试）

**看视频**
- B 站 / 腾讯视频 / 优酷 链接自动识别，调用官方播放器
- `.mp4 / .webm / .m3u8` 等直链走内置播放器，支持拖动进度、倍速 0.5×–3×、循环、画中画、全屏、截图
- 本地视频文件直接拖进播放器页面即可播放

## 兼容性说明

- **可以正常浏览**：新闻、百科、博客、文档、视频站等内容型网站。
- **可能部分失效**：强依赖登录态和大量后端接口的复杂站点（社交、邮箱、网盘等）。这类站点的接口请求走的是页面自身的跨域策略，代理层无法全部接管。
- **建议做法**：遇到白屏或报错，切一下渲染代理开关重试，或点击错误页的「在新窗口打开」直接访问原站。

根因在于渲染代理是「改写 + 转发」，而现代 SPA 会发起大量 XHR/fetch 请求并校验来源。要做到 100% 一致等于重写一个浏览器内核，超出网页方案的能力边界。

## 接口

| 路径 | 用途 |
| --- | --- |
| `/` | 浏览器界面 |
| `/__p?url=<encoded>` | 代理目标地址（支持 GET / POST） |
| `/__fav?u=<origin>` | favicon 代理 |
| `/__health` | 健康检查，返回服务端口 |

端口默认 `7180`，被占用时自动向上顺延（最多尝试 20 个）。
