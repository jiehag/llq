# Nova Browser

一个运行在网页里的浏览器。界面本身是网页，配一个本地渲染代理服务，让第三方网站能在窗口中被正常加载和浏览。

## 快速开始

双击 `start.bat`，或在命令行执行：

```bash
node server.js
```

然后浏览器打开 <http://127.0.0.1:7180>

> 必须通过 `http://127.0.0.1:7180` 打开。直接以 `file://` 方式打开 `index.html` 时，渲染代理不可用，大部分网站会因禁止 iframe 嵌套而加载失败。

## 为什么需要 server.js

浏览器安全策略里，网站可以通过 `X-Frame-Options: DENY` 或 CSP 的 `frame-ancestors` 声明「禁止被别的页面嵌入」。绝大多数网站都开了这个开关，所以纯粹的前端外壳无法加载它们。

`server.js` 做的是渲染代理：

| 能力 | 说明 |
| --- | --- |
| 解除嵌套限制 | 剥离 `X-Frame-Options`、CSP 等响应头 |
| 页面重写 | 注入 `<base>` 与导航劫持脚本，页面内点击、表单提交、`window.open` 都交回浏览器外壳处理 |
| 会话保持 | 服务端 Cookie Jar，按站点隔离，登录态可用 |
| 存储隔离 | 按站点给 `localStorage` / `sessionStorage` 加命名空间，避免所有网站共用同一份存储 |
| 资源透传 | 非 HTML 资源原样流式转发，保留 `Range` 分段 —— 视频可以拖动进度 |
| 编码兼容 | 自动识别 GBK / GB2312 等编码并统一转 UTF-8 |
| 图标代理 | `/__fav` 拉取站点 favicon，失败时回退为首字母色块 |

## 功能

**浏览**
- 多标签页：新建 / 关闭 / 恢复（Ctrl+Shift+T）/ 中键关闭 / 内存级前进后退
- 智能地址栏：自动区分网址与搜索词，带联想建议（可切换搜索引擎）
- 书签栏 + 书签管理、历史记录分组、下载记录
- 页面缩放、加载进度条、HTTPS 状态指示、明暗主题
- 站点级的渲染代理开关（遇到问题可单站切换重试）

**看视频**
- B 站 / 腾讯视频 / 优酷 链接自动识别，调用官方播放器
- `.mp4 / .webm / .m3u8` 等直链走内置播放器，支持拖动进度、倍速 0.5×–3×、循环、画中画、全屏、截图
- 本地视频文件直接拖进播放器页面即可播放

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 新建标签页 | `Ctrl + T` |
| 关闭标签页 | `Ctrl + W` |
| 恢复关闭的标签页 | `Ctrl + Shift + T` |
| 聚焦地址栏 | `Ctrl + L` |

## 兼容性说明

- **可以正常浏览**：新闻、百科、博客、文档、视频站等内容型网站。
- **可能部分失效**：强依赖登录态和大量后端接口的复杂站点（社交、邮箱、网盘等）。这类站点的接口请求走的是页面自身的跨域策略，代理层无法全部接管。
- **建议做法**：遇到白屏或报错，切一下渲染代理开关重试，或点击错误页的「在新窗口打开」直接访问原站。

根因在于渲染代理是「改写 + 转发」，而现代 SPA 会发起大量 XHR/fetch 请求并校验来源。要做到 100% 一致等于重写一个浏览器内核，超出网页方案的能力边界。

## 文件

```
nova-browser/
├── index.html    浏览器界面与前端内核（单文件）

└── README.md
```

## 接口

| 路径 | 用途 |
| --- | --- |
| `/` | 浏览器界面 |
| `/__p?url=<encoded>` | 代理目标地址（支持 GET / POST） |
| `/__fav?u=<origin>` | favicon 代理 |
| `/__health` | 健康检查，返回服务端口 |

端口默认 `7180`，被占用时自动向上顺延（最多尝试 20 个）。
